# 待解决问题

## 当前问题

### 项目选题

需要在以下候选方向中确认一个主场景：

1. 企业 IT 工单与运维协作 Agent：从故障描述、知识检索、工具诊断、方案生成、人工审批到执行和审计。
2. 电商订单异常处理 Agent：诊断订单、库存、支付、消息和履约问题，并在审批后执行补偿。
3. 企业研究与合规报告 Agent：多源检索、证据管理、并行分析、报告生成和人工复核。
4. 多租户 Agent 执行平台：允许配置模型、工具、权限和工作流，并运行不同业务 Agent。

当前推荐：以“企业 IT 工单与运维协作 Agent”为首个业务场景，后期再抽象为可复用的 Agent 执行平台。原因是它既能覆盖 Agent Loop、RAG、工具调用、Workflow、人工审批和评测，也自然引出异步任务、权限、安全、可观测性和可靠性，同时避免重复上一个订单微服务项目。

### 选题确认后再回答

- 任务中的哪些步骤必须由 Agent 自主决定，哪些应保持确定性？
- 第一个最小业务闭环需要哪些真实或模拟工具？
- 哪些操作只读，哪些操作需要人工批准？
- 如何定义任务成功，怎样构造第一批评测用例？
