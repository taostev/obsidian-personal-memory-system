# Agent 后端学习总体目标

## 目标陈述

通过亲手搭建并逐步演进一个业务级 Agent 项目，理解 Agent 是什么、它与聊天机器人及固定 Workflow 的区别，并在项目出现真实架构决策时学习候选架构、适用条件和取舍，最终具备应聘 Agent 后端开发工程师所需的原理理解、后端工程和系统设计能力。

## 成功标准

### 知识能力

- 能解释 LLM、Harness、Agent Loop、Tools、State、Memory、Environment 和 Guardrails 的职责及边界。
- 能根据业务约束比较 Workflow、单 Agent、混合架构、Router、Subagent、Handoff 和多 Agent，而不是只会套用框架。
- 能区分代码组织架构、业务流程架构、数据架构、通信架构和部署架构，并说明它们如何组合。

### 项目能力

- 完成一个具有真实业务目标、工具调用、状态持久化、权限边界和执行结果的 Agent 后端项目。
- 项目具备必要的测试、评测、日志/Trace、故障处理、安全控制和部署证据。
- 能用架构决策记录说明关键方案为什么选择、替代方案是什么、何时需要演进。

### 求职能力

- 能独立讲清业务问题、Agent 设计、后端架构、可靠性和效果评测。
- 能现场分析需求并选择合适架构，而不是背诵某个教程或框架 API。
- 能区分项目已经实现、实验验证和未来规划。
