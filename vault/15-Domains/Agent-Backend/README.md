# Agent 后端学习

这是一个独立的专题记忆模块，用于通过一个业务级 Agent 项目学习 Agent 原理、Harness、后端工程、架构选择、生产可靠性和求职表达。

## 记忆分工

- [[goal]]：稳定的求职目标与成功标准
- [[learning-map]]：项目驱动的学习循环与架构决策点
- [[progress]]：按日期追加的进度、产出、卡点和下一步
- [[decisions]]：已经确认的学习方法与技术取舍
- [[concepts]]：已经理解并验证的 Agent 后端知识
- [[open-questions]]：选题、未决架构和待验证问题
- [[resources]]：到达具体决策点后才采用的资料

## 边界

- 本专题不以 Hello-Agents、DeepSeek Harness、LangGraph 或其他单一教程/框架为中心。
- 项目代码、运行结果和测试事实应保存在将来对应的项目目录；本专题只保存学习目标、知识、决策和进度。
- Agent 项目实现、知识掌握评估和面试复习分开记录，避免把“已经实现”直接等同于“已经掌握”。
