# Java 后端学习

这是一个独立的专题记忆模块，用于保存学习路径、已掌握概念、技术选择、易错点和待解决问题。

## 记忆分工

- [[learning-map]]：学习阶段、路线和当前重点
- [[goal]]：学习总体目标，只保存稳定目标
- [[progress]]：学习进度，只保存按日期追加的学习记录
- [[concepts]]：概念理解、边界、对比和代码要点
- [[decisions]]：学习或技术实践中的已确认选择
- [[open-questions]]：尚未解决的问题和复习清单
- [[resources]]：课程、文档、文章和练习资源

## 边界

这里记录 Java 后端专题知识，不记录跨项目的个人表达偏好，也不替代具体项目的 `20-Projects/` 上下文。
